# tcslog 0.6.0

A release that breaks compatibility, hence the minor version. A
`VariableTsRc` record count is stored in 48 bits rather than 32, so the
stored format is 1.1.0 and a `VariableTsRc` record's header is 18 bytes
where it was 16. tcslog 0.5 refuses the logs this release writes, as a
1.0 reader refuses any newer minor version; this release still reads the
logs 0.5 wrote. `SegmentHeader` gains a field, `version_minor`, so code
that builds one field by field must set it. A dependent asking for 0.5
does not get this release.

The count's limit, `RECORD_COUNT_MAX`, is 2^48 - 1, about 89 years at
100,000 records a second, where 32 bits ended a session in under 12
hours. The C ABI is unchanged, so the shared library keeps the soname
`libtcslog.so.1`; only `TCSLOG_RECORD_COUNT_MAX` changes value.

Stored format: 1.1.0, which still reads 1.0.

### Added

- `SegmentHeader::version_minor`, the minor number of the stored format a
  file was written in, and `Format::data_header_len_in`, a data header's
  length in a file of that version.
- `make lint-packages` checks the packages with lintian and rpmlint, and
  their shell scripts with shellcheck, and fails on any finding not
  overridden with its reason.
- The .deb carries `/usr/share/doc/tcslog/copyright`, in Debian's
  machine-readable format, `changelog.Debian.gz` and lintian overrides,
  and the RPM a `%changelog` and a `Group`, all made from the version as
  the package is built.
- The .deb carries `DEBIAN/md5sums`, the MD5 of every file it installs,
  which `dpkg --verify` and debsums check an installed package against.

### Changed

- The .deb has dpkg's `ldconfig` trigger run the loader's cache rather
  than its `postinst` and `postrm`, which are gone.
- `downlink.py`, an example that is a script, is installed executable.
- A `VariableTsRc` record count is stored in 48 bits rather than 32, so
  its data header is 18 bytes and `RECORD_COUNT_MAX`
  (`TCSLOG_RECORD_COUNT_MAX` in C, `RECORD_COUNT_MAX` in Python) is
  2^48 - 1: about 89 years at 100,000 records a second, where 32 bits
  ended a session in under 12 hours. Files of format 1.0 are still read,
  with their 16-byte data headers and 32-bit counts. `SegmentHeader`
  gains a field, which breaks code that builds one field by field.
